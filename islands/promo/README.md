# 群島宣傳海報（LINE 分享預覽圖）設計說明

每次群島有新功能、新島上線，就做一張 1200×630 的海報，發到 LINE 群組宣傳。
這份文件記下設計目的與風格，之後每一張都照這個做，大家一看就知道是「全真群島」的消息。

## 設計目的
- **讓人想點進連結**：不是單純的遊戲截圖，要有標題、一句鉤子、看得出「能做什麼」。
- **一張只講一件事**：這次新增了什麼（新島、新功能），一眼看懂。
- **語氣**：溫暖、邀請、攜手同行；正能量，不催促、不抱怨。
- **降低門檻**：強調「點開就能逛」「不用登入」「可以匿名」這類沒有壓力的字眼。

## 版面（左文右圖）
| 區塊 | 內容 | 樣式 |
|---|---|---|
| 左上小字 | 系列名，例如「全真群島・新島上岸 🎉」 | 粗體 26px，主題色 |
| 大標題 | 島名或功能名，4～5 個字最好 | Noto Serif TC 900，約 116～124px，深藍黑 #1f2a3a |
| 彩色標籤 | 一句最短的鉤子，例如「你登島了嗎？」「撿到一封瓶中信」 | 圓角色塊、白字 46px，主題色 |
| 說明兩行 | 為什麼要點進來；最後半句用主題色強調 | 粗體 29px |
| 兩顆按鈕 | 主要行動＋「▶ 點開逛群島」 | 圓角膠囊，主題色＋橘色 #d9770a |
| 右半邊 | 拉近的 3D 島嶼截圖，往左淡進背景 | 白天（網址加 `?t=12:00`），隱藏所有介面 |
| 四張飄浮小卡 | 這個功能能做的 4 件事，每張一個 emoji＋短句 | 白底、彩色粗邊框、微微旋轉 |

## 配色
- 背景：淡藍 → 淡青 → 米色的斜向漸層（跟群島的海一樣粉嫩）
- 每張海報選一個**主題色**：
  - 登島、報名：紅 #d6336c
  - 漂流瓶、交流：藍 #2f80c9
  - 之後的新主題可以用：綠 #1d8a5f、金 #d9770a、紫 #7a5aa6
- 次要按鈕固定橘色 #d9770a；其他小卡邊框可以混用金、粉、綠、藍。

## 夜晚版（活動、晚會類）
- 活動是在晚上（例如凝聚晚會），可以改用夜晚版：截圖網址加 `?t=20:00`、時光捲軸拉到活動當天，讓燈串、燈籠都亮起來。
- 背景改成深藍 → 靛紫的斜向漸層（#1c2347 → #2c2f62 → #4a3459），點綴幾顆小星星和兩盞紅燈籠。
- 大標題改用米白 #fff4dc，系列名和強調字用金色 #ffcf4a，主題色用燈籠紅 #d0392b；說明文字用淡米色 #f3e6cf。
- 小卡維持白底彩框，陰影加深一點，才浮得起來。

## 島上文宣（3D 場景裡的布條、看板、牌子）
- 不要用紅底、白底、綠底：會被紅瓦、紅磚地、白牆、草地吃掉。一律「深藍底 #1d2547＋金字 #ffd75e／白字＋白色粗框」，字越大越好；主布條可以用紅底白字（喜氣），但一定要加白色粗框，才不會跟紅瓦混在一起。
- 牌面用不吃光影的材質（MeshBasicMaterial、toneMapped: false），白天不會被陰影壓暗，晚上自然像燈箱。
- 牌子不要跟建物、涼亭、樹重疊；放在空地上，白天、晚上各截一張圖確認。

## 製作方式
1. 用測試環境打開群島（`?t=12:00`），隱藏介面，把鏡頭拉近主角島，截一張 1000×700 當 `art.png`。
2. 複製 `poster-template.html`，改左邊文字、主題色、四張小卡。
3. 用瀏覽器（1200×630）開啟、等字型載入後截圖，存成 `promo/年-月-主題.png`。
4. 每張海報做一個自己的宣傳連結：在 `islands/` 底下開一個資料夾（例如 `bottle/`），放海報和一個只有分享預覽資訊的 `index.html`，點進來會直接跳到那座島（`../#島代號`）。這樣原本的群島連結預覽不用換。
