# 徽章牆 LINE 分享文案（2026-11）

連結：`https://steven4dev.github.io/yiguandao-2027-course/islands/badges/`
預覽圖：`islands/badges/og-badges.png`（標題「你亮了幾格？」）
規則：單行最多 12 個中文字、表情符號算約 2 字；語氣攜手同行，不催促。

## A　挑戰版（貼到群組，先丟一個鉤子）
```
🏅 欸，你的牆亮幾格？
我剛點亮了 10 格 😏
還有 2 格藏起來的，
我到現在都沒找到…

48 格暗格，
我們一起點亮好嗎？
👇 點開看你亮幾格
（連結）
```

## B　攜手版（貼給學長姐、新朋友）
```
🌱 一起來點亮徽章牆吧
逛逛島、寫瓶中信、
搭熱氣球…玩著玩著，
就亮起一格又一格 ✨

💚 還能綁 LINE 帳號，
換手機，徽章也跟著走！
（連結）
```

## C　短版（私訊、貼圖後補一句）
```
我的徽章牆亮了 10 格，
你呢？來跟我比 😆
（連結）
```

## 鉤子對照
| 位置 | 鉤子 | 心理 |
|---|---|---|
| 縮圖大標 | 你亮了幾格？ | 好奇＋想比較 |
| 縮圖畫面 | 暗格「？」＋一個紅點新徽章 | 想補滿、想點開 |
| 縮圖小卡 | 藏著 2 格隱藏徽章 | 解謎 |
| 訊息第一句 | 欸，你的牆亮幾格？ | 直接點名 |
| 訊息結尾 | 綁 LINE，換手機不歸零 | 怕白玩，給安心感 |
