# 徽章牆 LINE 分享文案（2026-11）

連結：`https://steven4dev.github.io/yiguandao-2027-course/islands/badges/`
預覽圖：`islands/badges/og-badges.png`（標題「你解鎖了幾枚？」）
規則：單行最多 12 個中文字、表情符號算約 2 字；語氣攜手同行，**不比較、不催促**——每一枚都是自己走過的足跡。

## A　好奇版（貼到群組，先丟一個鉤子）
縮圖已經問了「你解鎖了幾枚？」，訊息不要重複問，改用「徽章牆」「隱藏徽章」製造好奇，並帶到綁定 LINE。
```
🏅 群島有面徽章牆喔！
我逛著逛著，
就解鎖了 10 枚 ✨
還有 2 枚隱藏徽章，
一起慢慢找吧！

💚 現在還能綁定 LINE，
換手機，足跡也帶得走
👇 來看看你的足跡
（連結）
```

## B　攜手版（貼給學長姐、新朋友）
```
🌱 一起來收集足跡吧
逛逛島、寫瓶中信、
搭熱氣球…每一步，
都會解鎖一枚徽章 ✨

💚 綁定 LINE 帳號，
換手機，足跡也帶得走！
（連結）
```

## C　短版（私訊、貼圖後補一句）
```
我的群島徽章牆
解鎖 10 枚了 ✨
來逛逛，找找你的
第一枚吧 😊
（連結）
```

## 鉤子對照
| 位置 | 鉤子 | 心理 |
|---|---|---|
| 縮圖大標 | 你解鎖了幾枚？ | 好奇、回顧自己的足跡（不是跟人比） |
| 縮圖說明 | 每一枚，都是你走過的足跡 | 肯定感、被看見 |
| 縮圖小卡 | 藏著 2 枚隱藏徽章，慢慢逛，也許就遇見 | 探索的期待，沒有壓力 |
| 訊息第一句 | 群島有面徽章牆喔！ | 好奇，和縮圖的提問互補不重複 |
| 訊息結尾 | 綁定 LINE，足跡也帶得走 | 安心感 |

## 避免的說法
「比一比」「誰贏」「落後」「還沒亮」「快點」——改用「解鎖」「足跡」「慢慢來」「一起」。
