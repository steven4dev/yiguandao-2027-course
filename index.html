01

課程設計理念

26-45歲橫跨了剛出社會、拼事業、成家、育兒、照顧父母等多種人生階段。每堂課從一個不分年齡都會有感的生活痛點切入，作為打開話題的鉤子，再逐步收回到一貫道的修心功夫與道學核心，避免流於純粹的時事討論或說教。

對外・入口

生活化的標題與情境引子，讓人一眼就想坐下來聽——這是招牌，負責把人請進門。

對內・份量

每堂的「引子、道學核心、實修討論」三段式結構，道學核心約佔全堂三分之一至二分之一時間——這是食譜，決定端出來的菜有沒有料。

05

課程清單

第一堂

「我很好」是這年代最大的謊言

誠意正心

為什麼我們總是報喜不報憂、笑著扛下別人的情緒？從職場到家庭的「假裝沒事」文化，一起拆解這個誠信面具，找回誠意正心的真功夫。

引子・20分鐘從職場情緒勞動、家庭裡的假裝沒事文化切入，帶出「我很好」背後的疲憊
道學核心・35分鐘誠意正心的意涵，用生活故事說明真誠面對自己與他人的重要
實修討論・25分鐘【自介】以一句組員沒聽過的描述介紹自己（例：「我是一位曾在別人婚禮哭得比新娘還大聲的某某某」），再分享一次「假裝沒事」的具體經驗，練習說出今天真正的狀態
📚 講師參考
  • 《敢於脆弱》Brené Brown：「脆弱不是軟弱，而是勇氣的起點」——直接解釋為何「我很好」是代價高昂的習慣
  • 《情緒勒索》周慕姿：台灣語境，社青高度共鳴，可節錄第一章作為引子素材
  • 經典金句：《大學》「欲誠其意者，先致其知」——誠意從自知開始，不是從表演開始
第二堂

拿不走的，才是真的

本性、良心、天命

AI能寫報告、能畫圖，那人還剩下什麼不可取代？這堂課先花十分鐘聊聊AI帶來的職涯焦慮，但重點不在AI，而是回到一貫道講的本性、良心、天命——這些不是被淘汰、被取代的東西，才是真正決定一個人價值的核心。

引子・20分鐘AI衝擊職涯的現況與焦慮討論
道學核心・35分鐘本性、良心、天命的白話講解，說明何謂不可取代的價值
實修討論・25分鐘【自介】以一句組員沒聽過的描述介紹自己（例：「我是一位高中立志當太空人、後來把志向改了七次以上的某某某」），再思考並分享：我身上什麼是 AI 搶不走的？如果說不出來，從哪裡開始找？
📚 講師參考
  • 《活出意義來》Viktor Frankl：在集中營裡支撐人活下去的從來不是技能，而是「為何而活」的意義感——本性與天命的西方版詮釋
  • 經典金句：《論語》「知之者不如好之者，好之者不如樂之者」——AI 可以「知道」，但無法「喜愛」，更無法從中得到快樂
  • 經典金句：《中庸》「天命之謂性，率性之謂道」——天命不是命運，是你活出本性的那條路
第三堂

你也活成了父母的樣子？

反求諸己

我們常常發誓不要變成父母那樣，卻在某個瞬間發現自己脫口而出一樣的話、做一樣的反應。這堂課帶大家誠實面對原生家庭留下的印記，哪些該留、哪些該放。

引子・20分鐘分享一次「我也變成爸媽的樣子」的瞬間
道學核心・35分鐘反求諸己的功夫，說明如何看清而不苛責自己或父母
實修討論・25分鐘【自介】以一句組員沒聽過的描述介紹自己（例：「我是一位跟媽媽大吵後、隔天趁她睡著偷在枕頭下放道歉紙條的某某某」），再找出一個具體習慣，分辨它是該留的傳承還是可以鬆開的印記
📚 講師參考
  • 《原生家庭療癒》Susan Forward：系統梳理家庭留下的模式，不是要仇親，而是看清楚才能選擇
  • 《薩提爾的對話練習》：探討家庭溝通姿態（討好型、指責型、超理智型）如何在孩子身上複製，是反求諸己的實務版本
  • 經典金句：《論語》「見賢思齊焉，見不賢而內自省也」——看見父母的不足，不是判罪，是自省的起點
第四堂

照顧別人之前，先別丟了自己

孝道與量力而為

顧父母、顧小孩、顧同事的情緒——當「照顧」變成一種義務，付出的界線在哪裡？這堂課聚焦在「付出」這個行為本身：怎麼拿捏該做多少，才不會在照顧別人的過程中，把自己燃燒殆盡。

引子・20分鐘照顧父母、小孩、同事情緒的普遍壓力
道學核心・35分鐘孝道的本質與量力而為，破除「照顧＝無限犧牲」的迷思
實修討論・25分鐘【自介】以一句組員沒聽過的描述介紹自己（例：「我是一位曾同時照顧兩隻生病老狗、知道什麼叫做心疼到捨不得睡的某某某」），再找出目前付出中超過自己容量的一件事，練習說出一句拒絕或求助的話
📚 講師參考
  • 經典金句：《孝經》「身體髮膚，受之父母，不敢毀傷」——把自己燃燒殆盡，也是對父母賜予的一種毀傷
  • 《Set Boundaries, Find Peace》Nedra Tawwab：界線不是牆，是讓關係能持續的護欄
  • 經典金句：《論語》「躬自厚而薄責於人，則遠怨矣」——「厚」的前提是你還站得住，不是站著燃燒
第五堂

知足，是解藥還是藉口？

知足惜福

存不到錢的年代，長輩說「知足常樂」聽起來像風涼話。這堂課直球對決：知足到底是智慧，還是逃避現實的說法？

引子・20分鐘中年理財焦慮、存不到錢的現實壓力
道學核心・35分鐘知足惜福不等於躺平，說明知足與積極上進如何並存
實修討論・25分鐘【自介】以一句組員沒聽過的描述介紹自己（例：「我是一位帳戶只剩三位數那個月、還是硬請朋友吃了一頓飯的某某某」），再討論：你生命裡知足與藉口的分界線在哪裡？
📚 講師參考
  • 經典金句：《道德經》「知足者富」——真正的富有不在擁有多少，而在對自己所有的東西有多清醒
  • 《少，但是更好》Greg McKeown（Essentialism）：用取捨取代貪多，把精力集中在最重要那件事——知足的現代商業版
  • 《被討厭的勇氣》：阿德勒指出「自卑感來自比較」，知足的修練其實是停止用別人的尺量自己
第六堂

朋友圈變小了，是正常的嗎？

善緣與惜緣

出社會後，聯絡人越來越多，真正見面的朋友卻越來越少。這是成長的必然，還是關係正在悄悄流失？

引子・20分鐘討論出社會後交友圈縮小的普遍現象
道學核心・35分鐘善緣與惜緣的觀念，說明緣分有深淺、不必強求也不能輕忽
實修討論・25分鐘【自介】以一句組員沒聽過的描述介紹自己（例：「我是一位在捷運撿到夾著便條紙的二手書、然後花兩個月試著找到原本主人的某某某」），再列出一個一直想聯絡但沒聯絡的人，討論是什麼阻礙了你
📚 講師參考
  • 經典金句：《論語》「益者三友，損者三友。友直、友諒、友多聞，益矣」——你留下來的那幾個朋友，是哪一種？
  • 《關係黑洞》：探討現代人如何陷入表淺聯繫的假社交，而真正的緣在疏忽中流失
  • 民間諺語：「有緣千里來相會，無緣對面不相識」——緣不是被動等待，是主動珍惜
第七堂

那些年，我們一起憋過的話

五倫中的誠與和

用比較輕鬆、帶點懷舊感的分組活動開場，讓學員寫下（匿名也可以）一句「當年沒說出口的話」，現場抽出來討論。用遊戲感包裝，帶出委屈沒說出來會怎樣，怎麼講才不是壓抑、也不是爆炸。

分組活動・25分鐘匿名寫下「當年沒說出口的話」，現場抽出討論
道學核心・35分鐘五倫中的誠與和，說明如何不壓抑、不爆炸地表達
實修討論・20分鐘【自介】以一句組員沒聽過的描述介紹自己（例：「我是一位有一封寫好卻從來沒寄出去的信、在抽屜裡靜靜放了好幾年的某某某」），再練習用誠而和的方式重新說出那句當初憋住的話
📚 講師參考
  • 《非暴力溝通》Marshall Rosenberg：四步驟框架（觀察→感受→需要→請求）正是「有溫度地說真話」的具體操作，可直接帶進演練
  • 經典金句：《論語》「巧言令色，鮮矣仁」——一味討好、說人想聽的話，反而離仁最遠
  • 經典金句：《禮記》「情欲信，辭欲巧」——情感要誠實，表達要有方法，誠與和的並存不是矛盾，是功夫
第八堂

我這樣算失敗嗎？

安身立命、盡本分

沒結婚、沒買房、沒升遷……社會的時間表壓在每個人身上。開放討論場，讓學員先說出自己心裡「算不算失敗」的疑問，最後收回到一貫道對「成功」的定義——不是外在的房子、婚姻、職位，而是有沒有活出良心、盡了本分。討論結束前，每人寫下一句「對我來說，不算失敗的定義是____」，當場收回。

開放討論・25分鐘學員自由說出心裡「算不算失敗」的疑問與壓力
道學核心・35分鐘安身立命、盡本分，重新定義成功不在外在成就
收斂寫下・20分鐘【自介】以一句組員沒聽過的描述介紹自己（例：「我是一位曾同時收到五個城市的工作機會、最後選了薪水最低但覺得最對的那個的某某某」），再寫下：對我來說，不算失敗的定義是＿＿＿＿
📚 講師參考
  • 《活出意義來》Viktor Frankl：「人可以忍受任何一種怎麼活，只要他知道為什麼而活」——盡本分讓自己活得有方向感
  • 經典金句：《論語》「吾日三省吾身：為人謀而不忠乎？與朋友交而不信乎？傳不習乎？」——儒家的「成功」是每天的自省，不是年終排行榜
  • 經典金句：《孟子》「窮則獨善其身，達則兼善天下」——安身立命的基礎是先把「獨善其身」做好，這不是退讓，是修行的根基
第九堂

手機滑不停，你到底在逃避什麼？

收放心猿意馬

明明沒有要看什麼，手還是不自覺滑開手機。這個習慣背後，往往藏著一份不想面對的情緒或空虛。

引子・20分鐘覺察自己滑手機前的情緒狀態
道學核心・35分鐘收放心猿意馬的功夫，說明如何練習把浮動的心定下來
實修討論・25分鐘【自介】以一句組員沒聽過的描述介紹自己（例：「我是一位試過連續七天只在早晚各看一次手機、然後第八天就宣告失敗的某某某」），再設計一個屬於自己的「放下手機前的小動作」，並分享：你最常在逃避什麼？
📚 講師參考
  • 《深度工作力》Cal Newport（Deep Work）：注意力被設計成分散的，這不只是個人意志力問題，也是環境設計問題
  • 經典金句：《壇經》六祖惠能「本來無一物，何處惹塵埃」——心的本質是清淨的，滑手機是塵埃附著的過程
  • 經典金句：《大學》「心不在焉，視而不見，聽而不聞，食而不知其味」——一千年前就在說滑手機的狀態，只是那時滑的是別的東西
第十堂

情緒的急救包，你有自己的一份嗎？

靜心、內觀

不管是免費諮商還是找朋友訴苦，別人能幫你的都有限。這堂課教你打包一份「隨身可用」的急救工具——具體的靜心、內觀方法，遇到情緒卡關時，不用等別人來救，自己就能先穩住。

引子・15分鐘外部資源（免費諮商、朋友訴苦）的限制在哪裡
道學核心・40分鐘靜心、內觀的具體方法教學，現場帶做一次
實修演練・25分鐘【自介】以一句組員沒聽過的描述介紹自己（例：「我是一位曾獨自坐在海邊從日落等到天黑、那是我人生第一次覺得什麼都不做也沒關係的某某某」），再整理屬於自己的情緒急救包步驟卡（3–5個具體動作），並分享過去在情緒危機時如何撐過去的
📚 講師參考
  • 《正念的奇蹟》一行禪師：洗碗、呼吸、走路都可以是靜心——讀起來像詩，適合課後推薦學員慢慢翻
  • 《情緒》Lisa Feldman Barrett：情緒不是「發生在你身上」，而是「你建構出來的」——理解這點，就懂為何標記情緒可讓強度下降
  • 經典金句：《中庸》「喜怒哀樂之未發，謂之中；發而皆中節，謂之和」——靜心不是壓制情緒，是找到那個「未發」的穩定中心
第十一堂

跟自己相處，你及格嗎？

修身、獨處養性

不管單身、已婚還是有小孩，每個人都會有需要獨自面對自己的時刻。這堂課聊聊獨處的能力，怎麼把「跟自己相處」練成一種修行，而不是一種要逃避的空白。

引子・20分鐘獨處時刻對每個人（不分單身已婚）的普遍性
道學核心・35分鐘修身與獨處養性，說明獨處是修行而非逃避的空白
實修討論・25分鐘【自介】以一句組員沒聽過的描述介紹自己（例：「我是一位曾連續一個月每週六獨自去不同咖啡館、只帶筆記本不帶手機的某某某」），再分享一次跟自己好好相處或逃避自己的經驗，並設計一個本週的獨處練習
📚 講師參考
  • 《孤獨：回歸自我》Anthony Storr：獨處不是人際失敗的後果，而是創造力與自我整合的必要條件
  • 《瓦爾登湖》梭羅：「我到林中去，是因為我想過一種深思熟慮的生活」——問學員：你最後一次深思熟慮地過一天是什麼時候？
  • 經典金句：《論語》「君子求諸己，小人求諸人」——與自己相處的能力，正是「求諸己」的起點
第十二堂

洗碗也是修行，你信不信？

大隱於市、日常即修行

用一個小實驗開場：請學員回想今天做過最無聊的一件小事，然後現場翻轉——洗碗、通勤、回訊息，這些瑣碎日常其實都可以是修行現場。跟第十堂的「工具」概念呼應：工具學會了，還要會用在日常裡。

小實驗開場・20分鐘回想今天做過最無聊的一件小事
道學核心・35分鐘大隱於市、日常即修行，呼應第十堂學到的工具如何用進日常
實修討論・25分鐘【自介】以一句組員沒聽過的描述介紹自己（例：「我是一位太專心洗碗、發現用了十年的碗原來有條細小裂縫、然後莫名感動了一下的某某某」），再選一件本週會做的日常瑣事，設計帶著什麼意識去做它的「修行版」做法
📚 講師參考
  • 《禪者的初心》鈴木俊隆：「初學者的心有無限可能，專家的心可能性很少」——每次洗碗都帶著「初心」去洗，才是日常修行的精髓
  • 經典金句：《道德經》「為學日益，為道日損。損之又損，以至於無為」——修行不是加法，是在日常的減法裡找回最本質的專注
  • 禪宗公案：「砍柴挑水，無非妙道」——洗碗如果沒有這句話撐腰，直接引用它，讓日常即修行不只是口號，而是有根的道理
第十三堂

你上一次真心感謝，是什麼時候？

知恩報恩

感謝常常變成一句順口的客套話，而不是真正說進心裡的話。這堂課帶大家把感謝說得具體、說得真心。

實修暖身・20分鐘寫下一位還沒好好感謝過的人
道學核心・35分鐘知恩報恩的意義，說明報恩不是還債而是修辦的起點
實修討論・25分鐘【自介】以一句組員沒聽過的描述介紹自己（例：「我是一位有一張想給某人的卡片、放在錢包裡帶了將近三年還沒拿出來的某某某」），再練習說出一句完整的感謝：對方做了什麼、帶來什麼改變、所以我感謝你
📚 講師參考
  • 《感謝的力量》Robert Emmons（Thanks!）：研究顯示練習感恩的人在幸福感、睡眠品質、人際關係上都有顯著提升
  • 經典金句：《孟子》「老吾老以及人之老，幼吾幼以及人之幼」——把感謝的範圍從自己的恩人擴展到所有對世界有恩的人，是知恩報恩的最高境界
  • 經典金句：《詩經》「投我以木桃，報之以瓊瑤。匪報也，永以為好也」——報恩不是等值交換，是把那份情誼的溫度繼續傳遞下去
第十四堂

死亡教我們的事

生死大事、了脫生死

提到死亡，很多人直覺想迴避，但認真想過終點，才更知道怎麼過好剩下的日子。這堂課用平靜、不沉重的方式，一起聊聊無常這件事。

引子・20分鐘分享一次意識到生命有限的經驗（不必是重大事件）
道學核心・35分鐘生死大事與了脫生死的觀念，說明修辦與無常的關係
實修討論・25分鐘【自介】以一句組員沒聽過的描述介紹自己（例：「我是一位曾陪家人走完生命最後一段路、從那之後開始喜歡早起看第一道光的某某某」），再寫下：如果只剩一年，我最想完成的一件事——並討論那件事現在為什麼還沒做
📚 講師參考
  • 《當呼吸化為空氣》Paul Kalanithi：腦神經外科醫師得知罹癌後的回憶錄，直視死亡之後反而更清楚真正想要的生命是什麼
  • 《最後的演講》Randy Pausch：知道自己剩下多少時間，反而活出了最充實的樣子，適合引子階段帶動討論
  • 經典金句：《論語》「未知生，焉知死？」——孔子的回答看似迴避，實則是說：好好活，才是面對死亡的正解
第十五堂

這一年，我修了什麼？

反省、懺悔、立願

年終回顧場，帶大家梳理這一年的變化，說出自己的收穫，順便許下明年想修的功課。

回顧梳理・25分鐘學員梳理這一年參與課程後的變化與收穫
道學核心・30分鐘反省、懺悔的意義，說明立願的精神
立願分享・25分鐘【自介】以一句組員沒聽過的描述介紹自己（例：「我是一位曾在除夕夜翻出前一年願望清單、赫然發現三件事真的做到了然後嚇了自己一跳的某某某」），再說出：這一年我感謝＿＿；明年我想修的功課是＿＿
📚 講師參考
  • 《原子習慣》James Clear：改變不靠意志力，靠系統設計——立願之後，怎麼讓願景落地成一個小到做得到的習慣
  • 經典金句：《論語》「過而不改，是謂過矣」——反省的意義不在知道錯了，而在知道了之後有沒有動作
  • 經典金句：《論語》「吾日三省吾身」——修行是每天的事，不是年度總結，第十五堂不是終點，是下一個起點
