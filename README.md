# 一貫道全真社青班 2027年度課程企劃

一貫道全真社青班的年度課程規劃網站，適用對象為 26–45 歲學員，全年共 15 堂課，每堂 90 分鐘。

## 線上網址

https://steven4dev.github.io/yiguandao-2027-course/

## 內容

- 課程設計理念
- 全年修行旅程（拉近距離 → 深入探討 → 收斂實修 → 回顧立願）
- 全年時程（含開班、戶外聯誼、法會、結班等特別活動）
- 課程大綱總覽
- 十五堂課完整內容（標題、道學核心、本堂大綱）

- 投壺島（**打樣中、還沒放上群島**，島的外觀與位置之後再決定）：古禮「投壺」的小遊戲，單獨一頁 `islands/touhu-game/`（直接開網址就能玩）。三輪、每輪 4 矢——🌅 晨光（無風、近）→ 🌬️ 風起（起風、遠，瞄準線與落點圈會替你算風）→ 🛶 浮筏（夜裡、壺在筏上隨浪搖、不再替你算風）。投進壺口 2 分、穿過壺耳（貫耳）3 分，基本分滿分 36，另有時間加成（見下）；結果會依偏左偏右、太近太遠、擦邊、撞壺身給一句提示。三種稱號：靜心起步、漸入佳境、心手合一、矢直如心。
  - **三個控制：仰角（上下）、力道、左右**，三種操作共用
  - **力道＝距離**：力道條 0%＝離投擲者最近處 0.8 公尺、100%＝最遠處 4.4 公尺，中間等距對應（`TU.xMin／xMax`）。壺的位置是固定的比例（第一輪約 39%、第二輪約 56%、第三輪約 64%），不論仰角，推到壺的位置就會落在壺；出手速度由距離與仰角反推。
  - **操作方式選擇**：首頁仿拂塵試煉的難度開關，一條軸三個刻度（🎯 經典／🖐️ 觸控／📱 體感），可點、可左右拖，滑塊顏色跟著模式變；預設經典，選擇記在這支手機上，再按「開始投壺」。同一套物理（首頁可選，多人大廳每人各選）：
    - **🖐️ 觸控**：在畫面任何位置按住拖曳，落點圈「相對移動」（一碰就動，不必先推很遠；慢拖精細、快拖走遠；每一矢的起點是離壺 0.7～1.1 公尺的隨機位置，要自己拖到壺上；手指不擋住圈），放開就放箭；觸控模式的仰角固定（實測仰角只改變箭的弧線高低，入壺判定幾乎沒差，所以不放滑桿）。落點由同一套物理反推成左右與力道（`touchAim()`）。**手抖**：手指停得越穩落點圈晃得越小（每輪最大／最小幅度見 `WOBBLE`），想快就得冒險在圈還在晃時放開，想準就多花幾秒穩住，剛好跟時間加成形成取捨。拖到底部「取消區」放開＝取消；太短的點擊不算。按住期間鏡頭凍結，圈與壺的相對位置絕對穩定。滑鼠拖曳一樣能玩。
    - **📱 體感**：手機直立拿在胸前、背面對準壺，靜止約 1 秒「心定」校準（**每一矢都要**；心定後落點圈會先偏左或偏右 0.4～0.7 公尺，要轉動手機把圈拉回壺上，投完姿勢早就變了）。之後像觸控一樣直接決定「落點」：**左右**＝往左轉身或往左傾（像方向盤），落點往左，往右同理；**遠近**＝**手機越直立落點越近、越往前平躺越遠**（用絕對傾斜角 `TU.tiltNear`～`tiltFar`，約傾斜 28° 對準第一輪的壺）；**仰角**＝右側滑桿，用拇指調一次就記住。力道由落點與仰角自動算，不用另外蓄力。按「放箭」鈕或往前一送放箭（取按下前 160 毫秒的姿勢，不會被按按鈕晃偏）。用 `deviceorientation` 算出手機背面朝向與左右傾斜角（避開手機直立時 alpha／gamma 搶同一軸的問題）；準星左右跟手機相反時，按「⇄ 左右反了？」一鍵對調並記住。讀不到感測器或沒授權時，會提示改用觸控。
    - **🎯 經典三段式**（首頁下方小連結）：依序鎖定仰角（右側量表）→ 力道（左側量表）→ 左右（底部量表）。左右放最後，是因為風的偏移取決於飛行時間，前兩項定了，瞄準線才算得準；電腦可用空白鍵。
  - **掃 QR code 進房的人怎麼登入**：電腦大廳的 QR code 連到 `?room=房號`，進去直接是「加入房間」（房號已預填）；畫面最上方是綠色的「用 LINE 登入（名字自動帶入）」，也可以不登入、直接取個名字。從 LINE 登入回來若帶著房號，**會自動加入同一個房間**，不用再按一次（`tryAutoJoin()`）。
  - **LINE 登入與紀錄綁定**：首頁與多人大廳都有「👤 用 LINE 登入」（用群島共用的 `account-worker`，登入完回到投壺頁並保留網址上的 `?room=`）。登入後最高分、玩過幾場、累計入壺與貫耳、投矢數會綁在帳號上，換手機登入就自動取回（兩支手機各自累計沒辦法相加，所以**每項取較大值**，規則在 `islands/account-merge.js` 的 `islands-touhu`）；暱稱、操作方式、左右對調只留在手機、不上傳。沒登入照樣能玩，紀錄只存在這支手機。LINE 名字不會存在伺服器，只在登入當下交給手機顯示。
  - **時間加成（用來分高下、避免同分）**：每矢有 15 秒倒數（`TIME_LIMIT`），從「可以開始瞄準」算到放箭，**加成 ＝ 0.5 × 剩餘時間比例**，**只有投進（入壺、貫耳）的矢才有**，每矢最多 +0.5，一場最多 +6（不到基本分上限 36 的 17%）。設計取捨：①準度優先：快速入壺（2.5）仍不及慢速貫耳（3.0）；②只算「可以操作」的時間，不含飛行、慢動作、重播、等別人，所以網路慢或對手慢都不吃虧；體感的「心定」校準不計時（重新校準只暫停、不重置）；③倒數歸零不強迫放箭，只是沒有加成；④分工合投：兩位各有自己的 15 秒，加成用兩人剩餘比例的平均；⑤用「比例」不用秒數，不同操作方式在同一把尺上；⑥分數精度 0.1 分，同分機率大減，真的同分才進加賽。稱號門檻改成含加成的總分（≥30 矢直如心、≥20 心手合一、≥11 漸入佳境）。
  - **仰角與力道互相搭配**：低平快或高拋慢都能進壺（`pFor()` 會算出每個仰角剛好需要的力道）；拋得高、矢尖插得陡，有效的壺口較大，但飛得久、被風吹得更多。
  - **拋物線慢動作**：投出去後整段飛行放慢（`TU.slow`），快到壺口時更慢（`TU.slowNear`），入壺或落地後慢慢恢復；上下加電影黑邊，矢身後留一串白點畫出弧線。左右放箭前，畫面會先用虛線預測拋物線。
  - **場景細節**（全部程式即時生成、沒有圖檔，整個場景約 180 次繪製、1.7 萬個三角形）：銅壺有回紋腰帶、銅綠斑點與金屬反光（`RoomEnvironment` 環境反射，只給金屬材質用）；石板庭院、草蓆、竹林（竹葉用實例化一次畫完）、涼亭、岩石灌木、五盞紅燈籠與石燈（夜裡發光暈）；三輪三種光（午後、黃昏、夜）；落花（白天綠葉、黃昏楓紅）、夜裡螢火蟲、島邊浪花與海面波光、四周暗角。草蓆邊有一位小人偶賓客，投完會跟著反應（入壺歡呼、貫耳雙手高舉跳起、沒進搖頭攤手）。背景有輕輕的五聲音階撥弦；Android 手機會有輕震回饋。
  - **多人對戰**（房間伺服器在 `touhu-worker/`，說明與通訊協定見 [`touhu-worker/README.md`](touhu-worker/README.md)；**伺服器部署前，首頁不會出現「👥 多人對戰」按鈕**）：
    - **一對一賓主對投**、**二對二團體戰**；節奏可在大廳選：**同場對投**（各投各的、同一組風，每輪結算時看對方最精彩的一矢重播）或**輪流對投**（一人一矢，輪到對方時看他的拋物線慢動作）。
    - 二對二固定為**各自累計**（四人各投各的，隊伍分數是兩人相加）；「分工合投」已取消。
    - 三輪後同分就加賽，每人（隊）一矢，最多三次。收場以禮：贏的人說「承讓」，輸的人說「請益了」，不做排行榜，結果只有同房的人看得到。
    - 建房後有房號、QR code 與 LINE 邀請連結（`?room=ABCDE`）；對戰中上方有「拔河桿」：雙方共用一條，紅藍分界點隨分差左右移動（領先 15 分推到頭），領先方旁邊標示「領先 N 分」；房間畫面另有「📺 電腦觀戰」：把觀戰連結（`?watch=ABCDE`）用 LINE 傳到筆電，筆電打開就以大螢幕身分加入（不佔位置、只看不操作，看得到雙方即時分數與每一矢的拋物線），跟拂塵試煉的投影觀戰一樣；名字預設是 LINE 名字（已登入時），**可以改成暱稱**，改過的暱稱會被記住；沒登入就自己取，同房的朋友會看到這個名字；操作方式（點三下／體感）各人自選。
    - **電腦主持（大螢幕）**：首頁「用電腦主持」或網址加 `?host=1`。**大廳版型參考拂塵試煉**：左半是超大 QR code（寬度取 `46vh` 與 `34vw` 的較小值，1080p 約 500px）＋一行大字「📱 用手機掃描加入」＋紅色大房號；右半是狀態文字（「等玩家掃 QR code 加入（2/4）」）、座位卡（空位虛線、進來變實線、準備好變綠框；二對二左欄紅隊、右欄藍隊，空位寫明哪一隊）、大尺寸的對戰與節奏選項。開打後自動播放每位玩家的重播並顯示大計分條，適合戶外聯誼或法會前暖場。直式螢幕自動改成上下排列。
    - 手機各自跑物理，只把「這一矢的結果與軌跡」傳給對方（約 1～3 KB），對方用慢動作重播；掉線 20 秒內重連回原位，頁面重新整理也會自動回到房間。
  - 第一輪有綠色提示（力道、左右對準時變綠），之後不再有。聲音全用 Web Audio 合成（木矢入壺「咚」、貫耳的銅鈴、擦邊的「鏗」），沒有音檔。成績只存在玩家自己的瀏覽器（`islands-touhu`）。
  - 難度與手感集中在 `index.html` 的 `TU`（尺寸、瞄準範圍、體感靈敏度與門檻）與 `ROUNDS`（每輪距離、掃動速度、風、搖晃、天色）。彈幕與稱號文案是示範（`TH_DEMO`），待審定。
  - 預覽用網址參數：`?round=2`、`?round=3` 直接從那一輪開始；`?debug` 會把內部狀態掛在 `window.__TH`（測試用）。
- 外圈：其他 7 座幹部島；點幹部小人偶或名單可以看職稱、姓名、報名狀態與執掌；左後方是高鐵高架橋
- 聲音：預設開啟，打開網頁後點畫面任何地方就開始播放。漫步調的電鋼琴輕音樂；音效有高鐵轟隆轟隆經過、熱氣球噴火，以及每座島的特色聲音（收銀台、炒菜、木魚、風鈴…，點進那座島才聽得到）。全部用 Web Audio 即時合成，沒有音檔、沒有版權問題
- 資料：直接讀取報名表的 Google 表單回覆（跟報名分析頁同一份），每 5 分鐘或切回分頁時自動更新，連不上時改讀 `signup/data.json` 備份
