# 一貫道全真社青班 2027年度課程企劃

一貫道全真社青班的年度課程規劃網站，適用對象為 26–45 歲學員，全年共 15 堂課，每堂 90 分鐘。

## 線上網址

https://steven4dev.github.io/yiguandao-2027-course/

## 內容

- 課程設計理念
- 全年修行旅程（拉近距離 → 深入探討 → 收斂實修 → 回顧立願）
- 全年時程（含開班、戶外聯誼、法會、結班等特別活動）
- 課程大綱總覽
- 十五堂課完整內容（標題、道學核心、本堂大綱）

## 互動小遊戲（`game/`）

- **法會小天使**（`fahui-angel.html`、2.5D 版 `fahui-angel-25d.html`）：在新道親法會會場，照顧頭上冒出需求泡泡的新朋友。
- **褪下仙衣：八十億分之一**（`xianyi.html`）：參考《80億分之1》人生模擬，搭配歌曲〈回來佛堂〉的社青班推廣遊戲，約 6 分鐘。
  - 下凡抽籤 → 人生跑馬燈 → 25 歲抽人生劇本卡（科技新貴、成家立業、人脈社交、漂流、初衷遺忘、留學菁英）
  - 金幣／天幣／家人三條進度條，體現聖凡兼修；結局時金幣歸零（帶不走），天幣化成仙衣的光
  - 六個章節對應首頁六場專題；選「回來佛堂」會走一遍每日流程，並玩當月的下午活動小遊戲（迎新聯誼、藝術氣球、生命靈數、V·翻轉、蔬食料理王）
  - 五種結局：聖凡兼修・了愿返鄉、回來佛堂（三不離）、南天門外、飛車跑車大亨、漂流到底
  - 結局頁導向行事曆訂閱、社青班首頁與「揪一位夥伴一起回鄉」分享
  - 收集紀錄（結局、徽章、劇本卡）只存在玩家自己的瀏覽器
