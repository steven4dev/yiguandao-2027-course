# 一貫道全真社青班 2027年度課程企劃

一貫道全真社青班的年度課程規劃網站，適用對象為 26–45 歲學員，全年共 15 堂課，每堂 90 分鐘。

## 線上網址

https://steven4dev.github.io/yiguandao-2027-course/

## 內容

- 課程設計理念
- 全年修行旅程（拉近距離 → 深入探討 → 收斂實修 → 回顧立願）
- 全年時程（含開班、戶外聯誼、法會、結班等特別活動）
- 課程大綱總覽
- 十五堂課完整內容（標題、道學核心、本堂大綱）

## 互動小遊戲（`game/`）

- **法會小天使**（`fahui-angel.html`、2.5D 版 `fahui-angel-25d.html`）：在新道親法會會場，照顧頭上冒出需求泡泡的新朋友。
- **褪下仙衣：八十億分之一**（`xianyi.html`）：參考《80億分之1》的人生模擬，靈感來自歌曲〈回來佛堂〉。下凡抽籤，走完一生——名利帶不走，你帶走了什麼？約 12 分鐘，玩法與結局請親自下凡體驗。收集紀錄只存在玩家自己的瀏覽器。開始畫面右下角有版本編號，各版內容見 [`CHANGELOG.md`](CHANGELOG.md)。

## 第四期報名分析（`signup/`）

https://steven4dev.github.io/yiguandao-2027-course/signup/?v=3（分享用連結，LINE 會顯示預覽圖 `signup/og-signup.png`）

直接讀取報名表的 Google 表單回覆，開啟時讀一次，之後每 5 分鐘、或切回分頁時自動更新；連不上時改顯示 `signup/data.json` 的備份。

- 分析內容：報名人數、乾坤比例、年齡分布（標示 26–45 歲範圍外）、所屬單位、居住地區、介紹人與陪伴、報名時間軸、孩童隨行，以及自動產生的籌備建議與資料提醒
- 個資保護：只查詢需要的欄位，手機欄位不會讀進瀏覽器；所有姓名（學員、幹部、介紹人）都遮蔽中間字；生日只換算成年齡
- 幹部報名：介紹人欄填「幹部」代表本人是幹部，另外統計各組報名進度；學員的年齡、介紹人統計不含幹部。幹部名單寫在 `signup/index.html` 的 `CADRE_GROUPS`，跟首頁「同行夥伴」人事異動時要一起改（主班點傳師、帶班助理不列入）
- 試算表要維持「知道連結的任何人都能檢視」，關掉的話網頁會改顯示備份
- 連線狀態下方有版本編號（格式同褪下仙衣），各版內容見 [`signup/CHANGELOG.md`](signup/CHANGELOG.md)

## 全真群島（`islands/`）

https://steven4dev.github.io/yiguandao-2027-course/islands/（LINE 預覽圖 `islands/og-islands.png`）

溫暖玩具模型風格的 3D 微縮群島，用 Three.js 繪製，不需要建置。

- 中央：全真島＝全真道院（參考實景，地上四層），廣場小人偶＝已報名的夥伴；幹部穿該組顏色並帶職位配件，點人偶可以看是誰
- 內圈：9 座課程島（好玩島、好賺島、春遊島、好愛島、法會島、重啟島、秋遊島、走走島、歡樂島），依 2027 年日期順時針排列，用木橋串起一整年；每座島都是蓋好的樣子，上課當天島上有人潮、上過後開滿花
- 下午副課島：藝術氣球、生命靈數、V·翻轉後的人生、蔬食料理王，放在對應課程島外側（料理島附講師作品照片：群島用 `islands/photos/` 的 200 像素小縮圖，點開看 `img/Vegetarian Cooking Champion/` 的大圖）
- 加到手機桌面：圖示 `islands/icon-islands-180.png`（iPhone）、`icon-islands-192.png`／`icon-islands-512.png`（Android，寫在 `islands/islands.webmanifest`）
- 搜尋 🔍（右上角🏠前面，或點空中的瞭望氣球）：鏡頭飛到瞭望氣球旁邊停住，符合的島標籤會亮起來；課程、島名、日期、講師；打名字（全名或其中幾個字）可以找到自己或朋友的小人偶
- 登島＝報名：渡口島（登島報名處）和公關禮節島之間有竹筏固定往返，航線穿過好玩島和歡樂島之間的開口；品牌卡的「我要登島」、渡口島、竹筏、全真島／迎賓島／課程島資訊卡與導覽目錄都連到報名表（`SIGNUP_URL`，跟首頁「點我報名」同一份）
- 導覽：右上角「導覽」是島嶼目錄；時光膠囊兩側與資訊卡上的 ‹ › 依一年的課程路線切換「前一座島／下一座島」（只換島、不動日期），電腦可用鍵盤 ← →
- 幹部島以各組命名（學術島、總務島…）；公關禮節島負責迎賓，放在佛堂正門口前方，路線從這裡走到第一堂課
- 講師：課程島和下午島前緣站著講師（深青綠外套＋小黑板），點了或搜尋名字可以看單位、這堂課的日期主題，以及他也在哪些島上課
- 濟世靈山島（外海，好愛島和法會島方向中間）：**2026/11/10 正式開放**（`islands/index.html` 的 `JS_LIVE` 是 `true`；改回 `false` 就會重新圍起施工圍籬，測試碼 `JS_TEST_TOKEN` 仍可打開測試模式）。濟公活佛體感抽籤。淨手洗心（在靈泉上搓 2 秒）→ 誠心參拜（手機直立貼胸叩首三次）→ 搖晃籤筒 → 傾斜出籤，展開籤詩卷軸；手機用陀螺儀、加速度計（iPhone 按「開始參拜」時會詢問權限），電腦用滑鼠拖動代替並附 QR code。每個階段一開始飛過一句彈幕（參考拂塵試煉：短字從右飛進、停在正中間、往左飛出），資訊卡只留一句短話；每支手機每天一支，抽過的收進籤冊，可以分享到 LINE（分享連結 `islands/jishi/`）。108 支籤詩（6 類各 18 支）寫在 `islands/jishi/fortunes.js`，由 AI 仿濟公老師口吻臨摹，卷軸上標註「由 AI 臨摹，非出自濟公老師慈語」（`JS_DEMO`）；手感門檻在同一檔的 `JT`
- 清淨菩提島（外海，全真島正後方、高鐵橋外面）：**2026/11/05 正式開放**（`islands/index.html` 的 `PT_LIVE` 是 `true`；改回 `false` 就會重新圍起施工圍籬，測試碼 `PT_TEST_TOKEN` 仍可打開測試模式、不限每天一次）。吹散無明、雲開見日：整座島被雲霧蓋住，按「開始吹散無明」→ 開啟麥克風 → 對著麥克風長吹一口氣，雲霧由外往內被吹散，蓮花綻放、石碑浮現金字，畫面上方展開破關金句。吹氣偵測用 Web Audio 的 AnalyserNode 即時分析音量、頻譜平坦度、低頻占比（不錄音、不上傳），說話聲不算；不能用麥克風（拒絕授權、LINE 內建瀏覽器、沒有麥克風）時改成按住吹氣。每天一句，收進「菩提冊」，分享連結 `islands/puti/`。金句寫在 `islands/index.html` 的 `PT_QUOTES`，目前是示範文案，換成道場審定的正式慈語後把 `PT_DEMO` 改成 `false`；吹氣手感門檻在同一檔的 `QT`。全真島和清淨菩提島之間有一朵筋斗雲來回飛（雲上是 Q 版齊天大聖），點了就飛到清淨菩提島；右上角 ☁️ 按鈕可以搭上筋斗雲，從大聖後上方往下俯瞰、繞群島一圈（全程順時針、沒有髮夾彎，轉彎會壓車；約一分鐘，繞完拿「騰雲駕霧」徽章）；旁邊的 🎈 按鈕站進瞭望氣球的吊籃（瞭望氣球照真實結構建模：藤籃、四角麻繩立柱、頭頂燃燒器、往外拉到球皮開口的吊索；全部是 3D，拖曳轉頭、往下拖抬頭都對得上），以全真島為中心順時針一直繞，有噴火上浮、慢慢下沉、籃子搖晃的漂浮感（繞完一圈拿「乘風而行」徽章）。React／R3F 版的參考程式碼在 `docs/puti-island/`
- 廚神養成島（料理島外側，小木橋相連）：**施工中、只開測試**（`islands/index.html` 的 `CK_LIVE` 是 `false`；網址加 `?chef=ckq-5m2r#chef` 打開測試模式，`?chef=off` 關掉）。體感料理小遊戲在 `islands/chef-game/`：第一道菜南瓜濃湯，切南瓜（沿虛線劃：對半→挖籽→切瓣→切段→切丁）→ 顧火候（按住加火）→ 打成泥（手機畫圈，或手指畫圈）→ 吹涼（麥克風吹氣，或按住），再擺盤、在 3D 餐桌上取景拍照、套上《全真蔬食 VEGGIE》雜誌封面分享；封面縮圖與主廚名字只存在玩家自己的瀏覽器（`islands-chef`）。三杯杏鮑菇、彩虹潤餅捲之後加在同一頁的 `DISHES`。分享連結 `islands/chef/`，預覽圖 `islands/chef-game/og-chef.png`。從資訊卡進遊戲有不換頁的轉場「開店囉！」（金黃暖光、燈箱亮起、雜誌封面翻開接到遊戲；網址加 `notrans` 關掉）
- 投壺島（**打樣中、還沒放上群島**，島的外觀與位置之後再決定）：古禮「投壺」的小遊戲，單獨一頁 `islands/touhu-game/`（直接開網址就能玩）。三輪、每輪 4 矢——🌅 晨光（無風、近）→ 🌬️ 風起（起風、遠，瞄準線與落點圈會替你算風）→ 🛶 浮筏（夜裡、壺在筏上隨浪搖、不再替你算風）。投進壺口 2 分、穿過壺耳（貫耳）3 分，滿分 36；結果會依偏左偏右、太近太遠、擦邊、撞壺身給一句提示。三種稱號：靜心起步、漸入佳境、心手合一、矢直如心。
  - **兩種操作，同一套物理**：①「點兩下玩」——第一下鎖定左右（黃色瞄準線來回掃）、第二下鎖定遠近（落點圈沿著瞄準線前後滑），電腦可用空白鍵；②「體感玩」——手機背面對準壺、靜止約 1 秒「心定」校準，轉動手機左右瞄準、上下抬高壓低調遠近，**往前一送**放箭（也有「放箭」按鈕）。體感用 `deviceorientation` 算出手機背面朝向（避開手機直立時 alpha／gamma 搶同一軸的問題），放箭時取「揮出前 160 毫秒」的瞄準，不會被揮動本身晃偏。讀不到感測器或沒授權時，會提示改用點兩下。
  - 第一輪有綠色提示（對準時瞄準線與落點圈變綠），之後不再有。聲音全用 Web Audio 合成（木矢入壺「咚」、貫耳的銅鈴、擦邊的「鏗」），沒有音檔。成績只存在玩家自己的瀏覽器（`islands-touhu`）。
  - 難度與手感集中在 `index.html` 的 `TU`（尺寸、瞄準範圍、體感靈敏度與門檻）與 `ROUNDS`（每輪距離、掃動速度、風、搖晃、天色）。彈幕與稱號文案是示範（`TH_DEMO`），待審定。
  - 預覽用網址參數：`?round=2`、`?round=3` 直接從那一輪開始；`?debug` 會把內部狀態掛在 `window.__TH`（測試用）。
- 外圈：其他 7 座幹部島；點幹部小人偶或名單可以看職稱、姓名、報名狀態與執掌；左後方是高鐵高架橋
- 聲音：預設開啟，打開網頁後點畫面任何地方就開始播放。漫步調的電鋼琴輕音樂；音效有高鐵轟隆轟隆經過、熱氣球噴火，以及每座島的特色聲音（收銀台、炒菜、木魚、風鈴…，點進那座島才聽得到）。全部用 Web Audio 即時合成，沒有音檔、沒有版權問題
- 資料：直接讀取報名表的 Google 表單回覆（跟報名分析頁同一份），每 5 分鐘或切回分頁時自動更新，連不上時改讀 `signup/data.json` 備份
- 個資保護：手機欄位不讀進瀏覽器；畫面上直接顯示全名（讀不到即時資料、改用備份時，學員姓名是遮蔽過的），學員另外只顯示乾坤、單位、縣市與報名日期；報名資料只記幹部在名單裡的序號
- 課程資料寫在 `islands/index.html` 的 `COURSES`；幹部名單與各組執掌寫在同一檔的 `CADRE_GROUPS`、`ROLE_DUTIES`，跟 `signup/index.html`、首頁「同行夥伴」人事異動時要一起改
- 左上角有版本編號，各版內容見 [`islands/CHANGELOG.md`](islands/CHANGELOG.md)
