# 一貫道全真社青班 2027年度課程企劃

一貫道全真社青班的年度課程規劃網站，適用對象為 26–45 歲學員，全年共 15 堂課，每堂 90 分鐘。

## 線上網址

https://steven4dev.github.io/yiguandao-2027-course/

## 內容

- 課程設計理念
- 全年修行旅程（拉近距離 → 深入探討 → 收斂實修 → 回顧立願）
- 全年時程（含開班、戶外聯誼、法會、結班等特別活動）
- 課程大綱總覽
- 十五堂課完整內容（標題、道學核心、本堂大綱）

## 互動小遊戲（`game/`）

- **法會小天使**（`fahui-angel.html`、2.5D 版 `fahui-angel-25d.html`）：在新道親法會會場，照顧頭上冒出需求泡泡的新朋友。
- **褪下仙衣：八十億分之一**（`xianyi.html`）：參考《80億分之1》的人生模擬，靈感來自歌曲〈回來佛堂〉。下凡抽籤，走完一生——名利帶不走，你帶走了什麼？約 12 分鐘，玩法與結局請親自下凡體驗。收集紀錄只存在玩家自己的瀏覽器。開始畫面右下角有版本編號，各版內容見 [`CHANGELOG.md`](CHANGELOG.md)。

## 第四期報名分析（`signup/`）

https://steven4dev.github.io/yiguandao-2027-course/signup/?v=3（分享用連結，LINE 會顯示預覽圖 `signup/og-signup.png`）

直接讀取報名表的 Google 表單回覆，開啟時讀一次，之後每 5 分鐘、或切回分頁時自動更新；連不上時改顯示 `signup/data.json` 的備份。

- 分析內容：報名人數、乾坤比例、年齡分布（標示 26–45 歲範圍外）、所屬單位、居住地區、介紹人與陪伴、報名時間軸、孩童隨行，以及自動產生的籌備建議與資料提醒
- 個資保護：只查詢需要的欄位，手機欄位不會讀進瀏覽器；所有姓名（學員、幹部、介紹人）都遮蔽中間字；生日只換算成年齡
- 幹部報名：介紹人欄填「幹部」代表本人是幹部，另外統計各組報名進度；學員的年齡、介紹人統計不含幹部。幹部名單寫在 `signup/index.html` 的 `CADRE_GROUPS`，跟首頁「同行夥伴」人事異動時要一起改（主班點傳師、帶班助理不列入）
- 試算表要維持「知道連結的任何人都能檢視」，關掉的話網頁會改顯示備份
- 連線狀態下方有版本編號（格式同褪下仙衣），各版內容見 [`signup/CHANGELOG.md`](signup/CHANGELOG.md)

## 全真群島（`islands/`）

https://steven4dev.github.io/yiguandao-2027-course/islands/（LINE 預覽圖 `islands/og-islands.png`）

溫暖玩具模型風格的 3D 微縮群島，用 Three.js 繪製，不需要建置。

- 中央：全真道院佛堂島（參考實景，地上四層），廣場小人偶＝已報名的夥伴
- 內圈：9 座課程島，依 2027 年日期排列，用木橋串起一整年；時光捲軸可以看每座島從籌備中到開花
- 外圈：8 座幹部島與遊戲樂園島；點幹部小人偶或名單可以看職稱、遮蔽姓名（林○涵）、報名狀態與執掌；左後方是高鐵高架橋
- 聲音：右上角喇叭，環境音效（鳥叫、蟋蟀、青蛙、水波、高鐵經過）與五聲音階輕音樂，全部用 Web Audio 即時合成，沒有音檔、沒有版權問題
- 資料：直接讀取報名表的 Google 表單回覆（跟報名分析頁同一份），每 5 分鐘或切回分頁時自動更新，連不上時改讀 `signup/data.json` 備份；遊戲人次讀 `game/stats.json`
- 個資保護：手機欄位不讀進瀏覽器；學員只顯示人數；幹部只顯示職稱與遮蔽姓名，報名資料只記幹部在名單裡的序號
- 課程資料寫在 `islands/index.html` 的 `COURSES`；幹部名單與各組執掌寫在同一檔的 `CADRE_GROUPS`、`ROLE_DUTIES`，跟 `signup/index.html`、首頁「同行夥伴」人事異動時要一起改
- 左上角有版本編號，各版內容見 [`islands/CHANGELOG.md`](islands/CHANGELOG.md)

## 更新方式

直接編輯 `index.html` 並 commit 到 main 分支，GitHub Pages 會自動重新建置。
